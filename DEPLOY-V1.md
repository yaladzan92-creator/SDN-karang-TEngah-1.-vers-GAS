# Deploy V1 — SDN Karang Tengah 1

## A. Supabase
1. Buat project Supabase baru.
2. Jalankan SQL sesuai README.
3. Buat akun admin.
4. Salin Project URL dan Publishable Key ke dua file config.

## B. GitHub
1. Buat repository baru, contoh `webkarangtengah1`.
2. Upload **isi folder project**, bukan folder induknya.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Tunggu GitHub Pages aktif.

## C. Uji
- Beranda memuat profil dan statistik.
- `/admin/` membuka login admin.
- Tambah berita/gambar dan cek tampil di publik.
- Uji upload ekstrakurikuler.
- Uji sosial media.
